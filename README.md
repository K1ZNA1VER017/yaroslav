# банкетам.нет — сервис бронирования номеров в отелях

Редизайн существующего PHP-проекта: тот же стек (`index.php` + `api.php` + `lib.php` + `db.php` + MySQL),
новая предметная область — **онлайн-бронирование номеров в отелях**.

## Что изменилось

### Дизайн
* Новый визуальный язык: тёплая нейтральная палитра (кремовый фон, глубокий зелёный `#0f4d3d`, золотой акцент
  `#c39a4a`), крупная типографика Manrope/Inter, радиусы 18 px, мягкие тени. Эмодзи-иконки заменены на
  инлайновые SVG.
* Главная: hero-слайдер с фотографиями номеров, поверх него «парящая» форма поиска (даты, гости, категория),
  блок преимуществ, подборка популярных номеров, «как это работает».
* Каталог: карточки с реальными фото, типом, площадью, кроватями, рейтингом, ценой за ночь;
  фильтр по категориям + сортировка (популярные / дешёвые / дорогие / по площади).
* Бронирование: форма + «липкая» карточка расчёта, которая в реальном времени считает
  количество ночей и итоговую сумму.
* Кабинет: статистика (брони, ночи, подтверждено, отзывы), список броней со статусами, отзывы, форма отзыва.
* Админка: статистика по статусам, карточки заявок с гостями, датами, суммой и переключением статусов.
* Адаптив: на мобильных навигация превращается в нижнюю панель, все сетки перестраиваются в одну колонку.

### Логика (предметная область)
* Каталог номеров вынесен в `data/rooms.json` (его же читает статичное превью); `lib.php` кэширует его.
* Бронь теперь содержит: номер, ФИО гостя, телефон, e-mail, **дату заезда и выезда**, число гостей,
  **количество ночей** и **итоговую сумму**.
* Серверные проверки: вместимость номера, корректность дат (выезд позже заезда), e-mail, обязательные поля.
* Статусы брони: `new → confirm → paid → done`, а также `cancel`. Пользователь может отменить только новую бронь.
* Отзывы привязаны к номеру, а не к «залу».

## Запуск

Проект рассчитан на OpenServer / XAMPP:

1. Скопируйте папку в `domains/` (OpenServer) или `htdocs/` (XAMPP).
2. Проверьте параметры MySQL в начале `db.php`. По умолчанию хост — `MySQL-8.4` (OpenServer).
   Их можно переопределить переменными окружения:
   `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASS`, `DB_NAME` (по умолчанию `hotel_db`), `DB_SOCKET`.
3. Откройте `index.php` в браузере — база и таблицы (`users`, `bookings`, `reviews`) создаются автоматически.
4. Админка — кнопка ⚙ в правом нижнем углу. Логин `Admin26`, пароль `Demo26` (в `lib.php`).

### Статичное превью без сервера
`static-preview.html` — тот же интерфейс с демо-каталогом, но без PHP/БД. Открывается напрямую в браузере,
удобно для показа дизайна; авторизация и брони в нём не сохраняются.

## Структура

```
index.php              интерфейс (стили и JS внутри, PHP отдаёт каталог и состояние)
static-preview.html    версия без PHP для быстрого просмотра дизайна
api.php                JSON API: register/login/logout/state, booking.create/booking.cancel,
                       review.create, admin.login/logout/data/setStatus
lib.php                каталог номеров, состояние клиента, утилиты (ночи, суммы, склонения)
db.php                 подключение к MySQL и автосоздание схемы
data/rooms.json        каталог номеров (6 категорий)
assets/img/            фотографии номеров и логотип
```

* Отправка письма с подтверждением брони (сейчас подтверждение только в интерфейсе).
* Капча/рейт-лимит на формы регистрации и брони.
