# Гостиница.нет — онлайн-бронирование номеров бутик-отеля

Курсовой веб-проект системы онлайн-бронирования гостиничных номеров с модульной архитектурой фронтенда и бэкенда (`PHP + MySQL` для OpenServer / XAMPP + автономный интерактивный прототип без сервера).

## Ключевые возможности

### Дизайн и UX (Quiet-Luxury Hospitality)
* **Визуальная система**: тёплая палитра известняка и льна (`#F6F3EC`), глубокий хвойно-изумрудный акцент (`#124538`), матовая латунь (`#BD9247`), контрастная редакционная типографика `Cormorant Garamond` + `Manrope` с табличными цифрами (`tabular-nums`) для цен, дат и номеров.
* **Единый бренд и векторный логотип**: собственный SVG-знак `assets/img/brand-mark.svg`, полностью убраны следы старого шаблона и сломанные инлайн-иконки.
* **Главная страница**: кинематографичный hero-слайдер с интерактивной карточкой текущего номера, плавающая панель поиска с расчётом ночей, принципы отеля, флагманский блок «Президентский люкс», тёмная секция включённых привилегий, живой блок отзывов гостей с рейтинговой сводкой и пошаговый маршрут бронирования.
* **Интерактивный каталог**: проверка свободных дат в реальном времени (бейджи `Свободен` / `Занят`), фильтры категорий со счётчиками, поиск по удобствам и сортировка, а также **сравнение до 3 номеров** в отдельном модальном окне.
* **Карточка номера (модальное окно)**: подробные характеристики, удобства, реальные отзывы по номеру и мини-калькулятор стоимости с мгновенным переходом к брони.
* **Бронирование и ваучер**: автоматическая проверка пересечения дат с предложением свободных альтернатив, выбор дополнительных опций (трансфер, поздний выезд, романтический комплимент, детская кроватка), липкая карточка-смета, бесшовное оформление для гостя без принудительной стены входа и **электронный ваучер с поддержкой печати**.
* **Личный кабинет**: KPI-сводка, карточки броней с 4-этапным индикатором статуса (`Заявка → Подтверждена → Оплачена → Завершена`), открытие ваучера, отмена новой брони, список отзывов и форма оценки.
* **Панель администратора (PMS)**: финансовые и операционные KPI (подтверждённая выручка, заявки, новые, занятость сегодня), фильтрация по статусам, поиск, управление статусами, вкладка номерного фонда и просмотр отзывов.
* **Адаптивность**: мобильная нижняя панель навигации, удобные формы, кастомные уведомления (toasts) и модальные подтверждения вместо `alert`/`confirm`.

### Архитектура кода
Монолитные файлы (`index.php` на ~2000 строк и дублирующий `index1.html`) разделены на чистые модули с единым источником истины:

```
├── index.php                     # PHP-точка входа: гидрирует index.html данными из MySQL
├── index.html                    # Единый HTML-шаблон и автономный интерактивный прототип
├── api.php                       # JSON API-роутер (авторизация, доступность, брони, отзывы, админка)
├── db.php / lib.php              # Обратно совместимые обёртки над src/php/
├── data/
│   └── rooms.json                # Единый каталог номеров (6 категорий)
├── src/php/                      # Модульный бэкенд PHP + MySQL
│   ├── config.php                # Конфигурация БД, админа и дополнительных опций
│   ├── database.php              # Подключение MySQL, автосоздание таблиц и безопасные миграции
│   ├── helpers.php               # Валидация дат, склонения, JSON-ответы, расчёты
│   ├── rooms.php                 # Репозиторий номеров и проверка пересечения дат
│   ├── auth.php                  # Сессии, регистрация/вход, бесшовное создание аккаунта гостя
│   ├── bookings.php              # Создание брони (защита от овербукинга), отмена, админ-данные
│   ├── reviews.php               # Публичные и пользовательские отзывы
│   └── bootstrap.php             # Сборка начального состояния клиента
└── assets/
    ├── img/                      # Фотографии номеров (r1–r6) и SVG-логотип
    ├── css/                      # Токены, база, сетка, компоненты, секции, модалки, адаптив и печать
    └── js/                       # Модульный клиент без сборщика (data, utils, state, services, ui, views)
```

## Запуск

### Вариант 1: OpenServer / XAMPP (PHP + MySQL)
1. Скопируйте папку проекта в `domains/` (OpenServer) или `htdocs/` (XAMPP).
2. При необходимости переопределите параметры MySQL в `src/php/config.php` или через переменные окружения:
   `DB_HOST` (по умолчанию `MySQL-8.4`), `DB_PORT` (`3306`), `DB_USER` (`root`), `DB_PASS`, `DB_NAME` (`hotel_db`), `DB_SOCKET`.
3. Откройте `index.php` в браузере — база данных и таблицы (`users`, `bookings`, `reviews`) создадутся автоматически (существующие таблицы безопасно обновятся).

### Вариант 2: Автономный прототип без PHP и MySQL
Откройте `index.html` через любой локальный статический сервер (или напрямую в браузере). Приложение автоматически переключится на встроенный `localStorage`-бэкенд с предзаполненными демо-данными, проверкой пересечения дат, личным кабинетом и админ-панелью.
